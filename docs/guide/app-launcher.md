# App Launcher

The launcher is your central hub for managing containers. It opens automatically when you start Container Cove.

## Grid View

Apps are displayed as 72px icon tiles with:

- **Live status badges** — Green (running), yellow (starting), red (stopped), or red dot (unhealthy)
- **Search** — Filter by name in real time
- **Drag-and-drop reorder** — Arrange apps however you like
- **Right-click menu** — Launch, stop, edit, or remove

## Tabs

| Tab | Purpose |
|-----|---------|
| **Installed** | All apps you've added or installed |
| **Recommended** | Curated catalog of 26+ self-hosted apps |
| **Running** | Filter to only currently running containers |

## Catalog Installation

The Recommended tab includes one-click installs for popular services like Plex, Nextcloud, Home Assistant, Pi-hole, and more. Each comes with:

- Sensible default ports
- Pre-configured volumes
- Required environment variables (editable before install)

## Settings Footer

At the bottom of the launcher:

- **Theme toggle** — Switch between dark and light mode
- **Release channel** — Stable (default) or Beta
- **Open at Login** — macOS login item toggle
