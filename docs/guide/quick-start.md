# Quick Start

## Launch Container Cove

On first run, Container Cove displays a setup wizard to initialize Podman (Linux) or verify OrbStack (macOS). This is a one-time step that takes about 2–3 minutes.

## Browse the Catalog

Once the launcher appears:

1. Click the **Recommended** tab to see 26+ curated apps
2. Hover over any app card and click **GET** to install
3. Pre-filled environment variables and volumes are configured automatically

## Launch Your First App

Installed apps appear in the **Installed** tab:

1. Click the app tile to open its detail view
2. Click the **Launch** button (▶) to start the container
3. The embedded Web UI loads automatically when the container is healthy

## Add a Custom App

Click the **+** button in the launcher:

1. Enter a name and Docker image (e.g. `nginx:latest`)
2. Map host ports to container ports (e.g. `8080:80`)
3. Add environment variables and volumes as needed
4. Save — the app appears in your grid immediately
