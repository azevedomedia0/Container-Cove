# System Tray

Container Cove lives in your system tray for quick access even when the launcher is closed.

## Tray Menu

Right-click the tray icon to see:

- **Per-app status** — Each installed app shows a colored dot (green/running, red/stopped)
- **Click-to-launch** — Click any app name to start its container and open the Web UI
- **Stop All** — Gracefully stop every running container
- **Restart All** — Restart all containers in one action
- **Open Launcher** — Bring the main window to the front
- **Quit** — Exit Container Cove completely

## Status Dots

| Color | Meaning |
|-------|---------|
| 🟢 Green | Container is running and healthy |
| 🟡 Yellow | Container is starting or restarting |
| 🔴 Red | Container is stopped or unhealthy |

## macOS Menu Bar

On macOS, the tray icon appears in the menu bar. You can hide the dock icon and control everything from the menu bar if preferred.
